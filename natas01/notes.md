# Natas 01

## Objective

Access information required to progress to the next level despite a browser interface restriction.

## Skills Practiced

* Web page inspection
* Client-side security analysis
* Browser developer tools usage

## Tools Used

* Web Browser
* Browser Developer Tools (F12)
* View Page Source

## Challenge Description

The application indicated that the required information was present on the page, but right-click functionality had been disabled.

## Methodology

1. Logged into the application using the provided credentials.
2. Examined the visible content and challenge instructions.
3. Identified that the restriction was implemented in the browser interface.
4. Investigated alternative methods for inspecting page content.
5. Used browser features and developer tools to analyze the page.

## Key Observation

Disabling right-click functionality does not prevent users from accessing page source or browser developer tools.

## Lessons Learned

* Client-side restrictions should not be considered security controls.
* Browser functionality can often be accessed through multiple methods.
* Security mechanisms must be enforced on the server side rather than relying on user interface restrictions.

## Concepts Introduced

* Client-Side Controls
* Security Through Obscurity
* Source Code Inspection
* Browser Developer Tools
