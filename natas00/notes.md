# Natas 00

## Objective

Access the Natas 00 challenge and identify the information needed to progress to the next level.

## Skills Practiced

* Basic web application enumeration
* HTML source inspection
* Browser developer tools

## Tools Used

* Web Browser
* View Page Source
* Browser Developer Tools

## Methodology

1. Logged into the application.
2. Examined the visible page content.
3. Inspected the HTML source code.
4. Identified information not directly visible in the rendered page.

## Key Observation

The browser only displays a portion of the content sent by the server. Additional information may be present in the page source.

## Lessons Learned

* Always inspect page source during web assessments.
* Hidden information is not necessarily secure information.
* Client-side content should be examined before testing more advanced techniques.

## Concepts Introduced

* HTML Source Code
* Client-Side Visibility
* Information Disclosure
